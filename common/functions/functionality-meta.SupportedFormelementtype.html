    Function SupportedFormelementtype

    • SupportedFormelementtype(spec: TSupportedFormelementtypeSpec): MethodDecorator

      Method decorator for a functionality's functionality() method. Declares the FORMCYCLE form-element types the functionality supports, each optionally constrained by property values:

      @SupportedFormelementtype({ XTextField: { datatype: "dateDE" }, XTextArea: undefined })
      public static functionality(toLoad, toProcess) { … }

      A functionality without the decorator (or with an empty spec) applies to any element (fail-open), consistent with the existing @funcElement / manager tiers. To target any widget class EXPLICITLY — optionally narrowed by property constraints, e.g. { "*": { datatype: "dateDE" } } for "any element whose datatype is dateDE" — use "*" as the type.

      A property constraint VALUE may be an exact value, an OR-list of values, "*" (the property must be present and non-empty), or a glob containing * (e.g. datatype: "date*" matches every date-like datatype such as dateDE). All comparisons are case-insensitive.

      Parameters

      • spec: TSupportedFormelementtypeSpec

        The supported widget classes and their optional property constraints.
