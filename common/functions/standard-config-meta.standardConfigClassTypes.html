    Function standardConfigClassTypes

    • standardConfigClassTypes(
          classes: Readonly<Record<string, TStandardConfigClassSpec>> | undefined,
          cssClass: string,
      ): readonly string[] | undefined

      Extracts the FORMCYCLE widget-class list that a single CSS-Class of a standard configuration applies to, by reading the class's OWN entry of the config's classes map (the optimised shape where description + widget list are stored together — regular non-holistic config .json files). A legacy/manager entry that is a plain description string (or an entry without formelementtypes) contributes no types → that class is fail-open (applies to any element).

      Parameters

      • classes: Readonly<Record<string, TStandardConfigClassSpec>> | undefined

        The configuration's classes map (classes[cssClass] is a TStandardConfigClassSpec).

      • cssClass: string

        The CSS-Class (a classes/funcs key) to look up.
