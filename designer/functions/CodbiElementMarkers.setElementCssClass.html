    Function setElementCssClass

    • setElementCssClass(
          item: IMarkerItemLike,
          className: string,
          on: boolean,
      ): boolean

      Adds (on === true) or removes (on === false) ONE CSS class on the element's cssclasses property in every writable property bag, then nudges the persist differ so the change is synced.

      Unlike the data-cb-* attribute writers this only touches the named class — every UNRELATED class on the element is preserved. This is how a standard configuration is applied to a single element: the class itself is the runtime hook (each configuration's loadConfig({ targets: ".<class>", FUNC }) matches elements by that class), so no data-cb-func needs to be written.

      Parameters

      • item: IMarkerItemLike

        The target item.

      • className: string

        The CSS class to add/remove (e.g. CodBi_NoFutureDate).

      • on: boolean

        True to apply the class, false to remove it.

      Returns boolean

      True when at least one property bag was updated.
