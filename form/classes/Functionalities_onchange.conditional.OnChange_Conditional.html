    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): undefined

      Applies a functionality or attribute change onto a target element while a comparison between a watched field's value and a date reference holds. It re-evaluates on every change of the tagged element and is the correct mechanism for ORDERING comparisons (after/before a date, older/younger than, more/less than a number, from/up to) — NOT the Formcycle hiddenif* properties, which are for discrete option/checkbox/ empty state only.

      The TRUE/FALSE branches are attributes on the TAGGED element named data-cb-_T_<param> (applied when the comparison holds) and data-cb-_F_<param> (when it does not). The _T_/_F_ marker is stripped, so data-cb-_T_func becomes data-cb-func on the target. Omitting a branch means nothing happens in that case. To toggle visibility use HTML.SETAttribute on style, e.g.: data-cb-_T_func="HTML.SETAttribute", data-cb-_T_name="style", data-cb-_T_toset="display:block" data-cb-_F_func="HTML.SETAttribute", data-cb-_F_name="style", data-cb-_F_toset="display:none" Because the functionality runs only on change, hide the target AT LOAD with its own data-cb-func="HTML.SETAttribute" + data-cb-name="style" + data-cb-toset="display:none".

      Config Parameter:

      • Reference: The threshold the candidate's value is compared with. It MUST resolve to a Date, never a plain string: use the element placeholder { Date.FromString > 01.06.2026 ; DD.MM.YYYY } (or { Date.Today }). A literal "01.06.2026" has no getTime() and breaks the comparison.
      • Mode: GT (after/later/greater), GTEQ (on/after/at least), LT (before/earlier/less), LTEQ (on/before/at most), EQ (exactly) or NEQ (not equal). The enum is GTEQ/LTEQ — "GTE"/"LTE" are invalid.
      • Target: Dot-prefixed CLASS selector of the element whose attributes are changed (e.g. ".coSpaetbucherHinweis"), resolved inside the tagged field's container. NEVER an #id selector. Candidate and target MUST share the same container/fieldset.
      • DateFormat: The format of the CANDIDATE's value (datatype:"dateDE" → "DD.MM.YYYY", native date → "YYYY-MM-DD"). Omit it for non-date values; the fallback is the Date constructor.
      • Candidate: Dot-prefixed CLASS selector of the watched field (e.g. ".tfKursbeginn" — its own name when the tagged field is the watched one). NEVER an #id selector.

      Throws

      A CodBiError when a "DateFormat" is specified and a NON-EMPTY value (candidate or reference) cannot be converted to a Date. An EMPTY candidate is not an error: the false branch applies.
