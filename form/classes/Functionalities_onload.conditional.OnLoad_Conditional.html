    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): undefined

      Applies a functionality or attribute change onto a target element ONCE AT LOAD while a NUMERIC comparison between a value and a reference holds. Unlike OnChange_Conditional it registers NO event listener: it reads a value the element placeholders resolved at render time, compares it as a NUMBER, and applies the matching branch immediately. This is the correct mechanism for a load-time "more/less than a number" visibility toggle driven by an EP result (e.g. an array .length), where the comparison value is known the moment the page renders instead of on a later change event.

      The TRUE/FALSE branches are attributes on the TAGGED element named data-cb-_T_<param> (applied when the comparison holds) and data-cb-_F_<param> (when it does not). The _T_/_F_ marker is stripped, so data-cb-_T_func becomes data-cb-func on the target. Omitting a branch means nothing happens in that case. To toggle visibility use HTML.SETAttribute on style, e.g.: data-cb-_T_func="HTML.SETAttribute", data-cb-_T_name="style", data-cb-_T_toset="display:block" data-cb-_F_func="HTML.SETAttribute", data-cb-_F_name="style", data-cb-_F_toset="display:none" No separate load-time "hide" attribute is needed: the branch is applied immediately at load, so the target starts in whatever state the comparison dictates (omit the false branch to leave it as authored).

      Config Parameter:

      • Candidate: The value to compare. Use an element placeholder that resolves to a NUMBER or numeric string, e.g. data-cb-Candidate="{ JSON.Path > { bayvis.leistungsansprechpartner > 25439 } ; length }" (the EP is resolved into this parameter before the functionality runs) or a literal like 2.
      • Reference: The threshold the candidate is compared with, e.g. 1. May itself be an element placeholder that resolves to a number. A literal string is parsed with Number().
      • Mode: GT (greater than), GTEQ (at least), LT (less than), LTEQ (at most), EQ (exactly) or NEQ (not equal). The enum is GTEQ/LTEQ — "GTE"/"LTE" are invalid.
      • Target: Dot-prefixed CLASS selector of the element whose attributes are changed (e.g. ".coMehrfachZuordnungHinweis"), resolved inside the tagged field's container. NEVER an #id.

      Parameters

      Throws

      A CodBiError when Candidate or Reference is NON-EMPTY but does not parse to a finite number. An EMPTY candidate never fulfils the condition (the false branch applies).
