    checkAttributes

    • checkAttributes(): Promise<boolean>

      Processes all Elements that're tagged with a certain Attribute (data-cb-func) in order to activate CodBi-Functionalities. The Attribute data-cb-func is a CSV containing all CodBi-Functionalities to activate.

      When having found an Element this methods will look for all attributes named data-cb-.... When activating a CodBi-Functionality for an Element those attributes will be passed as a Key/Value-JSON to the functionality with the data-cb- prefix removed from the keys.

      This method also looks for global variables related to the functionality to be used. Those may be specified in the GUI's "Variables" section and got to be prefixed with the functionality's name (using underscores instead of dots separators however (e.g. time.frame becomes time_frame)) followed by the variable's name without the data-cb- prefix (e.g. Time_Frame_MaxField). For being useful to define values that're common to multiple functionalities but still pertain the possibility to overwrite those values when needed, global variables have the least precedence and will be overwritten by the ones the Element has.

      The attribute data-cb-apply may be used to apply all global variables and all attributes of the Elements to the ones specified by the CSS-Selector-TSV, which is this attribute's value (take care to use data-org-name in CSS-Attribute-Selectors in order for the application to also work in repetitive containers). Global variables and those received from the original Element may be overwritten simply by re-specifying the variable-attribute on the Elements data-cb-apply refers to where suitable.

      The data-cb-Loader attribute, if set to "none" (case insensitive), does deactivate the loader-animation only, not the disabling if HTMLInputElements as long as the tagged Element hasn't been processed.

      CAUTION: The suspension of processing will also result in delaying the disabling for input of all further elements.

      Returns Promise<boolean>

      A Promise < boolean > that resolves a soon as all Elements where initially processed and the application of functionalities as the retrieval of Element Placeholder values has been triggered.

      Throws

      A CodBiError when the processing of an Element throws one.

      Implementation of CodbiGlobal.checkAttributes

    ProtectedconfigAttributeCarriers

    • configAttributeCarriers(target: Element): Element[]

      The element(s) that receive a configuration's data-cb-* attributes.

      Normally the matched target itself. When a standard-configuration CSS class is rendered onto a WRAPPER around the actual control, though, that target is not a control at all — while most functionalities (e.g. Date.Min, HTML.Input.Cleave) require one, so the configuration would be applied to an element that rejects it and silently do nothing. In that case the SINGLE form control contained in the wrapper is used instead.

      Targets that ARE controls, and container-like targets (fieldset, form, body, head, html — e.g. the panel/accordion classes, which are scoped to a whole section), are returned unchanged, so a class spanning many fields never leaks its functionality onto unrelated controls.

      Parameters

      • target: Element

        The element matched by the configuration's targets selector.

      Returns Element[]

      The element(s) the configuration attributes are written to.

      ): { base: string; path: { index?: number; key?: string }[] }

      Splits a CodBi <[...]> reference into the field part and an optional property/JSON path.

      Three notations are supported:

      • <[Base]> — the field's value (unchanged).
      • <[Base::path]> — explicit path; Base may be this, any name or any CSS selector.
      • <[Base.path]> — shorthand, ONLY when Base is a bare name (no leading selector character and no combinator) — e.g. <[tfJson.total]>.

      The shorthand is deliberately not applied to selector-like references, because .tfName would otherwise be split into the class tfName and the path .... Use <[.tfName::value]> there.

      Parameters

        The raw reference between <[ and ]>.

      Returns { base: string; path: { index?: number; key?: string }[] }

    ProtectedresolveFieldReference

    • resolveFieldReference(fieldReference: string, reference?: Element): string

      Resolves a single CodBi <[...]> field reference against the DOM.

      The reference is either this (the value of the element the parameter belongs to) or a CSS selector / CSS class of another field. A selector is searched in the nearest ancestor XContainer / XFieldSet of the referencing element first and in the document as fallback — which keeps repeatable containers isolated. A bare identifier is treated as a CSS class first (backwards compatible with the AI functionalities), then as a data-name and finally as a plain selector.

      A path may be appended — <[tfJson.total]> (JSON property), <[.tfJson::items[0].name]> (JSON path) or <[this::innerHTML]> (DOM property). See CodBi.parseFieldReference.

      Parameters

        The raw reference between <[ and ]>.

      • Optionalreference: Element

        The element the parameter belongs to (context for this and the scope).

      Returns string

      The referenced field's current value or NULL if it cannot be resolved.

    ProtectedresolveFormcyclePlaceholders

    • resolveFormcyclePlaceholders(value: string): string

      Resolves Formcycle placeholders in the notation [%XXX%] within a parameter string by replacing them with the CURRENT value of the referenced field. The field is looked up by its CodBi data-name attribute (falling back to the native name attribute); input/textarea/select controls contribute their current value, other elements their value attribute or text content. Placeholders whose field does not exist (or is not present in the DOM) are left untouched so nothing silently disappears. Runs BEFORE element placeholders/functionalities are invoked, so a parameter like { Data.CSV > [%tfCsv%] } feeds the referenced field's value into the EP.

      Parameters
