    Staticfunctionality

    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): void

      Registriert die „DQ.Table.View“-Funktionalität, die eine Tabelle mit dem Ergebnis einer Formcycle-DataQuery einfügt das getaggte HTMLElement und ermöglicht den Export dieser Tabelle in eine Excel-Datei (.xlsx) über eine Schaltfläche.

      Konfigurationsparameter:

      • „Spalten“: ERFORDERLICH – Eine CSV, die die anzuzeigenden Spalten definiert. Jede Spalte ist label;datacolumn;jsonFlag mit einem optionalen vierten Eintrag ;width: z.B. Anrede;Anrede;false,Unternehmen;Unternehmen;true,Nachricht;Nachricht;false;30. „label“ ist der in der Tabelle/Excel-Datei angezeigte Header, „datacolumn“ ist der Name der Spalte Innerhalb des DataQuery-Ergebnisses markiert „jsonFlag“ („true“ / „1“ / „yes“) die Spalte als enthaltend JSON, damit seine Zellen einen maximierbaren JSON-Viewer darstellen (verwenden Sie „false“ / „0“ / „no“ für „plain“) Spalten; Aus Gründen der Abwärtskompatibilität wird eine einfache Zahl an dieser Position als behandelt width) und width (optional) definiert die Breite der Spalte (Zeichen in der Excel-Datei, Pixel auf dem Bildschirm).
      • „DataQuery“: ERFORDERLICH – Der Name des Datasource-Query auf dem Formcycle-Server, dessen Ergebnis angezeigt werden soll (z. B. „INHALT.Eigentuemerdialog_Dezember_2025“). Die Abfrage wird über „$.xutil.getDataQuery“ ausgeführt.
      • „CSS“: Ein optionaler string einer oder mehrerer (durch Leerzeichen getrennter) CSS-Klassen zur Anwendung auf beide der getaggte Container und die injizierte Tabelle.
      • „FileName“: Der Name der exportierten Excel-Datei ohne Erweiterung. Die Erweiterung ist immer „.xlsx“. Standardmäßig ist „Exportieren“.
      • „SheetName“: Der Name des Arbeitsblatts in der exportierten Excel-Datei. Der Standardwert ist „sheet1“.
      • ExportButton: Ein optionaler CSS-Selektor eines vorhandenen <button>/<a>, der das auslösen soll Export. Wenn es weggelassen wird (oder kein passendes Element gefunden wird), wird die Tabelle ohne gerendert Export-Button — der Excel-Export ist dann einfach nicht verfügbar.
      • „Zentriert“: Ob der Inhalt der Tabellenzellen („“s) zentriert ist. Standardmäßig ist „true“; auf „false“ / „0“ / „no“ setzen, um die Zellen linksbündig zu halten.
      • „ExcludeColumns“: Eine optionale CSV-Datei mit Spaltennamen (abgeglichen mit dem „Label“ der Spalte oder datacolumn), die vom Excel-Export ausgeschlossen sein sollen (sie bleiben im sichtbar Tisch). Z.B. Nachricht,Wichtige_Hinweise.

      Parameters

      • toLoad: { [key: string]: unknown }

        Provided by the CodBi.

      • toProcess: Element

        Provided by the CodBi - the container the table shall be injected into.

      Returns void

    Protected StaticnormalizeJson

    • normalizeJson(raw: unknown): string

      Normalisiert einen Rohzellenwert vor der JSON-Analyse.

      Eine DataQuery-JSON-Spalte kann ein JSON-Array mit einem führenden Komma direkt nach der öffnenden Klammer liefern (z.     Protected StaticparseColumns

    • parseColumns(columns: unknown): TableViewColumn[]

      Analysiert den „Columns“-Parameter in ein Array von TableViewColumns.

      Der Parameter ist eine CSV, deren Spalten durch „,“ und deren Einträge durch „;“ getrennt sind: label;datacolumn;jsonFlag mit einem optionalen vierten Eintrag ;width (z. B. Alter;Alter;true oder Name;Name;falsch;25). Der dritte Eintrag ist das JSON-Flag (true/1/yes → JSON-Spalte; false/0/no → einfache Spalte). Aus Gründen der Abwärtskompatibilität steht an der dritten Stelle eine einfache Zahl als die alte „Breite“ behandelt.

      Der CodBi-Attributprozessor wandelt ein Komma, das einen Wert enthält, bereits in einen string-Array um, also beides Es werden ein vorab aufgeteilter Array und ein roher string akzeptiert.

      Parameters

      • columns: unknown

        The raw Columns-parameter value.

      Returns TableViewColumn[]

      Die analysierten TableViewColumns.
