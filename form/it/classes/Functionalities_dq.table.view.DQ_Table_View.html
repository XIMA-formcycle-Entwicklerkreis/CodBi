    Staticfunctionality

    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): void

      Registra la funzionalità "DQ.Table.View" che inserisce una tabella che mostra il risultato di un Formcycle-DataQuery in il tag HTMLElement e consente di esportare la tabella in un file Excel (.xlsx) tramite un pulsante.

      Parametro di configurazione:

      • Colonne: REQUIRED - Un CSV che definisce le colonne da mostrare. Ogni colonna lo è label;datacolumn;jsonFlag con una quarta voce opzionale ;width: per esempio. Anrede;Anrede;falso,Unternehmen;Unternehmen;vero,Nachricht;Nachricht;falso;30. "label" è l'intestazione mostrata nella tabella/file Excel, "datacolumn" è il nome della colonna all'interno del risultato DataQuery, jsonFlag (true / 1 / yes) contrassegna la colonna come contenente JSON in modo che le sue celle restituiscano un visualizzatore JSON massimizzabile (usa false / 0 / no per semplici colonne; per compatibilità con le versioni precedenti un numero semplice in questa posizione viene trattato come larghezza) e "larghezza" (facoltativo) definisce la larghezza della colonna (caratteri nel file Excel, pixel sullo schermo).
      • DataQuery: REQUIRED - Il nome di Datasource-Query sul Formcycle-server il cui risultato deve essere visualizzato (ad esempio INHALT.Eigentuemerdialog_Dezember_2025). La query viene eseguita tramite $.xutil.getDataQuery.
      • CSS: Un string opzionale di una o più classi CSS (separate da spazi) da applicare a entrambi il contenitore etichettato e la tabella iniettata.
      • FileName: Il nome del file Excel esportato senza estensione. L'estensione è sempre ".xlsx". L'impostazione predefinita è "Esporta".
      • SheetName: Il nome del foglio di lavoro all'interno del file Excel esportato. Il valore predefinito è "foglio1".
      • ExportButton: Un opzionale selettore CSS di un <pulsante>/<a> esistente che attiverà il esportare. Quando omessa (o non viene trovato alcun elemento corrispondente) la tabella viene resa senza alcuno pulsante di esportazione: l'esportazione in Excel semplicemente non è disponibile.
      • Centered: se il contenuto delle celle della tabella (<td>s) è centrato. Il valore predefinito è true; impostato su false / 0 / no per mantenere le celle allineate a sinistra.
      • ExcludeColumns: un CSV facoltativo di nomi di colonna (corrispondenti all'"etichetta" o all'etichetta della colonna) datacolumn) che saranno esclusi dall'esportazione Excel (rimangono visibili nella tavolo). Per esempio. Nachricht,Wichtige_Hinweise.

      Parameters

      • toLoad: { [key: string]: unknown }

        Provided by the CodBi.

      • toProcess: Element

        Provided by the CodBi - the container the table shall be injected into.

      Returns void

    Protected StaticnormalizeJson

    • normalizeJson(raw: unknown): string

      Normalizza un valore di cella non elaborato prima dell'analisi JSON.

      Una colonna DataQuery-JSON può fornire un array JSON con una virgola iniziale subito dopo la parentesi di apertura (ad esempio [,{...},{...}], [ ,{...}] o [,,{...}]) che non è un JSON valido. Tali virgole iniziali vengono rimosse (il primo viene sostituito con [, gli altri semplicemente eliminati). Una distinta base UTF-8 preceduta da alcuni risultati di DataQuery viene rimosso anche in modo che il valore possa essere analizzato (e renderizzato/esportato) correttamente.

      Parameters

      • raw: unknown

        The raw cell value.

      Returns string

      Il string normalizzato.

    Protected StaticparseColumns

    • parseColumns(columns: unknown): TableViewColumn[]

      Analizza il parametro "Colonne" in un array di TableViewColumns.

      Il parametro è un CSV le cui colonne sono separate da , e le cui voci sono separate da ;: "label;datacolumn;jsonFlag" con una quarta voce opzionale ";width" (ad es. "Alter;Alter;true" o Nome;Nome;falso;25). La terza voce è il flag JSON (true/1/yes → colonna JSON; false/0/no → colonna semplice). Per compatibilità con le versioni precedenti, un numero semplice nella terza posizione è trattata come la "larghezza" legacy.

      Il processore di attributi CodBi trasforma già una virgola contenente un valore in un string-Array quindi entrambi sono accettati un Array pre-diviso e un string non elaborato.

      Parameters

      • columns: unknown

        The raw Columns-parameter value.

      Returns TableViewColumn[]

      Il file TableViewColumns analizzato.
