    Protected StaticurlPattern

    • get urlPattern(): RegExp

      L'espressione regolare che rileva un URL all'interno di un valore di cella semplice. Corrisponde a una (sotto)stringa che inizia con uno schema noto (http://, https://, ftp://, mailto:, tel:) o un prefisso www., fermandosi a spazio bianco o <>": in questo modo viene selezionato un URL incorporato in un testo più lungo (ad esempio "vedi https://acme.example/x") senza acquisire la punteggiatura finale o il testo adiacente. Stringhe di query (ad esempio un collegamento Formcycle ?fcpuid=…) compresi trattini, barre e = vengono mantenuti come parte dell'URL.

      Il testo non è convalidato rispetto a un TLD: il solo prefisso "www." (ad es. "www.ima" vs "www.imap") altrimenti essere ambiguo, quindi qualsiasi sequenza "www." seguita da un'etichetta separata da punti viene trattata come un collegamento.

      Returns RegExp

    Staticfunctionality

    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): void

      Registra la funzionalità "DQ.Table.View" che inserisce una tabella che mostra il risultato di un Formcycle-DataQuery in il tag HTMLElement e consente di esportare la tabella in un file Excel (.xlsx) tramite un pulsante.

      Parametro di configurazione:

      • Colonne: REQUIRED - Un CSV che definisce le colonne da mostrare. Ogni colonna lo è label;datacolumn;jsonFlag con una quarta voce opzionale ;width: per esempio. Anrede;Anrede;falso,Unternehmen;Unternehmen;vero,Nachricht;Nachricht;falso;30. "label" è l'intestazione mostrata nella tabella/file Excel, "datacolumn" è il nome della colonna all'interno del risultato DataQuery, jsonFlag (true / 1 / yes) contrassegna la colonna come contenente JSON in modo che le sue celle restituiscano un visualizzatore JSON massimizzabile (utilizzare false / 0 / no per semplici colonne; per compatibilità con le versioni precedenti un numero semplice in questa posizione viene trattato come larghezza) e "larghezza" (facoltativo) definisce la larghezza della colonna (caratteri nel file Excel, pixel sullo schermo).
      • DataQuery: REQUIRED - Il nome di Datasource-Query sul Formcycle-server il cui risultato deve essere visualizzato (ad esempio INHALT.Eigentuemerdialog_Dezember_2025). La query viene eseguita tramite $.xutil.getDataQuery.
      • CSS: Un string opzionale di una o più classi CSS (separate da spazi) da applicare a entrambi il contenitore etichettato e la tabella iniettata.
      • FileName: Il nome del file Excel esportato senza estensione. L'estensione è sempre ".xlsx". L'impostazione predefinita è "Esporta".
      • SheetName: Il nome del foglio di lavoro all'interno del file Excel esportato. Il valore predefinito è "foglio1".
      • ExportButton: Un opzionale selettore CSS di un <pulsante>/<a> esistente che attiverà il esportare. Quando omessa (o non viene trovato alcun elemento corrispondente) la tabella viene resa senza alcuno pulsante di esportazione: l'esportazione in Excel semplicemente non è disponibile.
      • Centered: se il contenuto delle celle della tabella (<td>s) è centrato. Il valore predefinito è true; impostato su false / 0 / no per mantenere le celle allineate a sinistra.
      • ExcludeColumns: un CSV facoltativo di nomi di colonna (corrispondenti all'"etichetta" o all'etichetta della colonna) datacolumn) che saranno esclusi dall'esportazione Excel (rimangono visibili nella tavolo). Per esempio. Nachricht,Wichtige_Hinweise.
      • UrlPartToReplace: un CSV facoltativo di parti URL che devono essere sostituite in ogni URL visualizzato come testo all'interno di una cella (e nell'esportazione in Excel). Applicato solo quando è impostato "UrlPartReplacement". anche; entrambi i CSV sono combinati per posizione: la prima voce viene sostituita con la prima voce di UrlPartReplacement, il secondo con il secondo e così via. Per esempio. "https://interno.esempio,http://interno.esempio".
      • UrlPartReplacement: un CSV opzionale di sostituzioni per UrlPartToReplace, combinati per posizione. Una voce vuota rimuove la parte corrispondente dall'URL. Per esempio. "https://public.esempio,https://public.esempio".

      Parameters

      • toLoad: { [key: string]: unknown }

        Provided by the CodBi.

      • toProcess: Element

        Provided by the CodBi - the container the table shall be injected into.

      Returns void

    Protected StaticnormalizeJson

    • normalizeJson(raw: unknown): string

      Normalizza un valore di cella non elaborato prima dell'analisi JSON.

      Una colonna DataQuery-JSON può fornire un array JSON con una virgola iniziale subito dopo la parentesi di apertura (ad esempio [,{...},{...}], [ ,{...}] o [,,{...}]) che non è un JSON valido. Tali virgole iniziali vengono rimosse (il primo viene sostituito con [, gli altri semplicemente eliminati). Una distinta base UTF-8 preceduta da alcuni risultati di DataQuery viene rimosso anche in modo che il valore possa essere analizzato (e renderizzato/esportato) correttamente.

      Parameters

      • raw: unknown

        The raw cell value.

      Returns string

      Il string normalizzato.

    Protected StaticparseColumns

    • parseColumns(columns: unknown): TableViewColumn[]

      Analizza il parametro "Colonne" in un array di TableViewColumns.

      Il parametro è un CSV le cui colonne sono separate da , e le cui voci sono separate da ;: "label;datacolumn;jsonFlag" con una quarta voce opzionale ";width" (ad es.     Protected StaticparseUrlReplacements

    • parseUrlReplacements(
          partToReplace: unknown,
          replacement: unknown,
      ): UrlPartReplacement[]

      Analizza i parametri UrlPartToReplace e UrlPartReplacement in un elenco di UrlPartReplacements.

      Entrambi i parametri sono CSV e sono combinati per posizione: la prima voce di UrlPartToReplace viene sostituita con la prima voce UrlPartReplacement, la seconda con la seconda e così via. Per esempio. UrlPartToReplace = "https://intern.example,http://intern.example" insieme a UrlPartReplacement = "https://public.example,https://public.example" riscrive ogni host interno di un rendering URL alla sua controparte pubblica. Vengono utilizzate solo tante coppie quante sono quelle fornite dal più breve dei due CSV; voci di Gli UrlPartToReplace senza una controparte vengono ignorati. Una voce vuota in UrlPartReplacement rimuove il file parte corrispondente dall'URL.

      Come con parseColumns il processore di attributi CodBi potrebbe già aver trasformato una virgola contenente un valore in a string-Array, quindi sono accettati sia un Array pre-diviso che un string non elaborato. Quando uno dei parametri è assente/vuoto, non avviene alcuna sostituzione.

      Parameters

      • partToReplace: unknown

        The raw UrlPartToReplace-parameter value (CSV of the parts to replace).

      • replacement: unknown

        The raw UrlPartReplacement-parameter value (CSV of the replacements).

      Returns UrlPartReplacement[]

      Il UrlPartReplacements analizzato (vuoto quando i parametri non sono entrambi impostati).

    Protected StaticrenderTextCell

    • renderTextCell(
          td: HTMLTableCellElement,
          raw: string,
          replacements?: UrlPartReplacement[],
      ): void

      Rende una cella semplice (non JSON). Qualsiasi URL trovato nel valore viene trasformato in un HTMLAnchorElement cliccabile che si apre in una nuova scheda/finestra, mentre il testo circostante viene mantenuto così com'è. Sono presenti più URL per cella supportato. La punteggiatura della frase finale (., ,, ;, :, !, ? e parentesi quadre/virgolette di chiusura) è lasciato fuori dal collegamento.

      Ogni URL riconosciuto viene visualizzato in modo identico a href + target="_blank" + standard Ancoraggio rel="noopener noreferrer": nessun URL è mai nascosto dietro data-url/href="#".

      Quando vengono forniti UrlPartReplacement, vengono applicati a ogni URL riconosciuto prima che venga visualizzato, quindi sia il testo del collegamento che il suo "href" mostrano l'URL riscritto.

      Parameters

      • td: HTMLTableCellElement

        The HTMLTableCellElement to fill.

      • raw: string

        The raw cell value.

      • replacements: UrlPartReplacement[] = []

        The UrlPartReplacements to apply to every recognised URL (optional).

      Returns void
