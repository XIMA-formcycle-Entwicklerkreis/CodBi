    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): void

      Aggiunge un pulsante del microfono a un HTMLInputElement di tipo 'testo' o a un HTMLTextareaElement per input da voce a testo tramite un Whisper-Model self-hosted sul server Formcycle.

      Parametri di configurazione:

      • VoiceHotkey: scorciatoia da tastiera per attivare/disattivare la registrazione. Impostazione predefinita: "Alt+A".
      • Lingua: codice lingua a due lettere per Whisper (ad esempio de, en, fr). Se omesso, Whisper rileva automaticamente la lingua.
      • Segnaposto: testo segnaposto personalizzato per il campo. Visualizzato solo quando "ShowHint" è "true".
      • ShowHint: se impostato su true, mostra il suggerimento del tasto di scelta rapida come testo segnaposto. Impostazione predefinita: "falso".

      DSGVO/GDPR — Riconoscimento vocale in sede

      A differenza della variante API Web Speech (MEDIA.INPUT.SPEECH), questa funzionalità elabora tutti i dati audio localmente sul server Formcycle (o qualsiasi server locale tramite OpenAI /v1/audio/transcriptions API (*controlla il Whisper.kt Class-Documentation per maggiori informazioni)) utilizzando un modello Whisper self-hosted tramite whisper.cpp.

      Nessun dato audio lascia il server. Non esiste alcuna dipendenza da Google, Microsoft, OpenAI o qualsiasi altro provider cloud. Ciò lo rende pienamente conforme a DSGVO/GDPR senza richiedere un consenso aggiuntivo per l'elaborazione vocale basata su cloud.

      Differenza da MEDIA.INPUT.SPEECH:

      Caratteristica MEDIA.INPUT.SPEECH MEDIA.INPUT.SPEECH.WHISPER
      Elaborazione API cloud del browser (in tempo reale) Server locale (batch)
      I dati lasciano il dispositivo? Sì (nuvola) No (solo localhost)
      È necessario il consenso DSGVO? Sì (art. 13) No
      Intermedio in tempo reale? Yes Sì
      Browser support Chrome, Edge (limitato) Tutti i browser moderni
