    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): undefined

      Applica una funzionalità o una modifica di attributo a un elemento di destinazione durante un confronto tra un elemento guardato vale il valore del campo e vale un riferimento alla data. Si rivaluta ad ogni "modifica" dell'elemento taggato e lo è il meccanismo corretto per ORDINARE i confronti (dopo/prima di una data, più vecchio/meno di, più/meno di una numero, da/fino a) — NON le proprietà hiddenif* del Formcycle, che sono per opzioni/caselle di controllo/ solo stato vuoto.

      I rami TRUE/FALSE sono attributi sull'elemento TAGGE denominato data-cb-_T_<param> (applicato quando il confronto è valido) e data-cb-_F_<param> (quando non è così). Il marcatore _T_/_F_ viene rimosso, quindi "data-cb-_T_func" diventa "data-cb-func" sulla destinazione. Omettere un ramo significa che in quel caso non succede nulla. Per attivare/disattivare la visibilità utilizzare HTML.SETAttribute su style, ad esempio: data-cb-_T_func="HTML.SETAttribute", data-cb-_T_name="stile", data-cb-_T_toset="display:block" data-cb-_F_func="HTML.SETAttribute", data-cb-_F_name="style", data-cb-_F_toset="display:none" Poiché la funzionalità viene eseguita solo in caso di "modifica", nascondi il target AT LOAD con il suo data-cb-func="HTML.SETAttribute" + data-cb-name="style" + data-cb-toset="display:none".

      Parametro di configurazione:

      • Riferimento: la soglia con cui viene confrontato il valore del candidato. DEVE risolversi in Date, mai una stringa semplice: utilizzare l'elemento segnaposto { Date.FromString > 01.06.2026 ; GG.MM.AAAA } (o { Data.Oggi }). Un valore letterale "01.06.2026" non ha getTime() e interrompe il confronto.
      • Modalità: GT (dopo/dopo/maggiore), GTEQ (on/dopo/almeno), LT (prima/prima/meno), LTEQ (acceso/prima/al massimo), EQ (esattamente) o NEQ (non uguale). L'enumerazione è GTEQ/LTEQ — "GTE"/"LTE" non sono validi.
      • Target: selettore CLASS con prefisso punto dell'elemento i cui attributi vengono modificati (es. ".coSpaetbucherHinweis"), risolto all'interno del contenitore del campo taggato. MAI un selettore #id. Il candidato e il target DEVONO condividere lo stesso contenitore/fieldset.
      • DateFormat: il formato del valore del CANDIDATO (datatype:"dateDE" → "DD.MM.YYYY", data nativa → "AAAA-MM-GG"). Ometterlo per valori diversi dalla data; il fallback è il costruttore Date.
      • Candidato: selettore CLASS con prefisso punto del campo osservato (ad esempio ".tfKursbeginn" - il proprio nome quando il campo contrassegnato è quello osservato). MAI un selettore #id.

      Parameters

      • toLoad: { [key: string]: unknown }

        Provided by CodBi.checkAttributes / CodBi.loadConfig.

      • toProcess: Element

        Provided by CodBi.checkAttributes / CodBi.loadConfig.

      Returns undefined

      Throws

      A CodBiError when a "DateFormat" is specified and a NON-EMPTY value (candidate or reference) non può essere convertito in Date. Un candidato VUOTO non è un errore: si applica il ramo falso.
