CodBiBayVISAuskunftAnsprechpartnerdetailsAction

class CodBiBayVISAuskunftAnsprechpartnerdetailsAction : IPluginServletAction

Dieses Servlet fungiert als Nano-Server, um Anfragen von einem Formular mithilfe des CodBi zusammen mit dem weiterzuleiten BayVIS-bezogene Funktionalitäten der BayVIS-API verhindern so die Offenlegung von Zugangsdaten.

Konfigurationsschlüssel:

  • BayVIS_Benutzername: Der Benutzername, mit dem Sie sich bei der BayVIS-API anmelden.

  • BayVIS_Passwort: Das Passwort zur Anmeldung an der BayVIS-API.

  • BayVIS_EP_Ansprechpartnerdetails: Optionale Angabe, wo der Endpunkt für den Abruf liegt Das Autoritätsverzeichnis ist zu finden.
