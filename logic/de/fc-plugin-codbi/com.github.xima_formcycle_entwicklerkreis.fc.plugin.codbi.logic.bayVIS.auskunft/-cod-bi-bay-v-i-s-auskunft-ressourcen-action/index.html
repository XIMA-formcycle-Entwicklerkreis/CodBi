CodBiBayVISAuskunftRessourcenAction

class CodBiBayVISAuskunftRessourcenAction : IPluginServletAction

Einzelner Nano-Server-Proxy für jede BayernPortal (BayVIS) REST v3-Ressource, die dediziert ist Servlets (CodBiBayVISAuskunftBehoerdenverzeichnisAction, CodBiBayVISAuskunftBehoerdendetailsAction, CodBiBayVISAuskunftGebaeudedetailsAction, CodBiBayVISAuskunftAnsprechpartnerverzeichnisAction, CodBiBayVISAuskunftAnsprechpartnerdetailsAction) decken nicht ab.

Die dedizierten Servlets und ihre Elementplatzhalter bleiben unberührt – dieses Servlet fügt nur hinzu Ressourcen dokumentiert unter „https://www.baybw-services.bayern.de/restapi.htm“:

Im Gegensatz zu den dedizierten Servlets (deren Elementplatzhalter die XML-Standarddarstellung von analysieren). die API) fragt dieses Servlet das Portal nach „application/json“, damit die neuen Elementplatzhalter dies tun können Analysieren Sie den Text mit „JSON.parse“, ohne die Namen der XML-Umschläge zu erraten.

Anforderungsheader:

  • „Dienst“ (erforderlich): einer der oben genannten Schlüssel auf der Whitelist – ein unbekannter Schlüssel wird abgelehnt Das Frontend kann mit den Anmeldeinformationen des Plugins niemals einen beliebigen Pfad aufrufen.

  • „ID“ / „ID2“ / „ID3“ (optional, abhängig von der Ressource): die numerischen Pfad-IDs; sie sind Prozentcodiert und in „{id}“, „{id2}“ und „{id3}“ ersetzt.

  • „Full“ (optional): „true“ / „false“ – wird als „full“-Abfrageparameter weitergeleitet.

  • „Gemeindekennziffer“ (optional): 8-stelliger amtlicher Gemeindeschlüssel – weitergeleitet als Gemeindekennziffer.

Konfigurationsschlüssel:

  • BayVIS_Benutzername: Der Benutzername, mit dem Sie sich bei der BayVIS-API anmelden.

  • BayVIS_Passwort: Das Passwort zur Anmeldung an der BayVIS-API.

  • BayVIS_UpdateCycle: Stunden, nach denen ein zwischengespeichertes Ergebnis erneut angefordert wird.

  • BayVIS_CacheSize: Maximale Anzahl zwischengespeicherter Antworten, die der begrenzte LRU-Cache vor dem speichern darf Die zuletzt verwendeten Einträge werden entfernt (Standard DEFAULT_CACHE_SIZE, d. h. 256). Groß genug, um Halten Sie jede Sammlung auf der Whitelist (die größte, „/leistungsbeschreibungen“, ist mehrere MB groß) plus viele ID-verschlüsselte Detaildatensätze gleichzeitig.

  • BayVIS_EP_Ressourcen: Optionale Basis-URL der REST v3 API (Standard). https://www.bayernportal-webservices.bayern.de/rest/allgemein/v3).
