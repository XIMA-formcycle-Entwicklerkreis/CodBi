AiAssistantLog

object AiAssistantLog

Behält bei und lädt das Änderungsprotokoll aller CodBi-KI-Assistenten-Inferenzen (Formular + Workflow).

Jeder erfolgreiche „Lauf“ von AICodBiAssistant zeichnet eine Zeile in der Tabelle „codbi_ai_assistant_log“ auf Enthält den Zeitstempel, die Eingabeaufforderung des Benutzers, die klassifizierte Absicht, das verwendete Modell und eine Struktur JSON-Beschreibung der vorgenommenen Änderungen:

  • form – { "widgetsCreated": [...], "widgetsRemoved": [...], "classesSet": [...], "attributesSet": [...] }. Die CodBi-Attribute „data-cb-func“ / „data-cb-*“ sind mit gekennzeichnet kind: "func" / kind: "param", damit die Benutzeroberfläche sie als spezielle, aufklappbare Elemente darstellen kann Zeigen Sie die von einer Funktionalität verwendeten CodBi-Parameter an.

  • Workflow – [ { "name": "...", "nodeType": "FC_EMAIL", "params": {...} }, ... ] wo jeweils Der Eintrag beschreibt einen Workflow-Knoten und die dafür definierten Parameter.

Das Tabellenschema wird von CodbiEntities verwaltet über db/changelog/codbi-ai-assistant-log-changelog.xml.
