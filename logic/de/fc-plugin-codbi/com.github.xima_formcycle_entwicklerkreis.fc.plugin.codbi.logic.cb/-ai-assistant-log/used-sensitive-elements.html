usedSensitiveElements

fun usedSensitiveElements(formChanges: JsonObject, sensitive: Set<String>): List<String>

Bestimmt, welche der konfigurierten sensiblen CodBi-Elementnamen (sensibel, bereits in Kleinbuchstaben geschrieben) wurden tatsächlich in der angegebenen Änderungsbeschreibung (formChanges) verwendet. Passend ist Groß-/Kleinschreibung wird nicht beachtet und es werden Folgendes abgedeckt:

  • widgetsCreated[].name / .className

  • „classesSet[].classes[]“ (CSS-Klassen mit Standardkonfiguration)

  • attributesSet[].attributes[], dessen Wert den Elementnamen enthält (z. B. ein data-cb-func). Wert oder ein „data-cb-*“-Parameterwert, der einen EP-Platzhalter wie „{ pluto ... }“ enthält)

  • variablesSet[].name (globale Variablen)

Return

Die übereinstimmenden Namen sensibler Elemente, sortiert für eine stabile Ausgabe.

Parameters

formChanges

The change description produced by computeFormChanges.

sensitive

The lowercased set of sensitive element names (from AI.logSensitiveElements).
