ClarificationQuestionFilter

object ClarificationQuestionFilter

Erzwingt EINE Regel der Klarstellungsaufforderung im Code: Eine Frage darf niemals zweimal gestellt werden.

Ein kleines lokales Modell neigt dazu, ein bereits empfangenes Detail erneut abzufragen – oder das Zielelement enthält bereits (beobachtet: „Welche Art von Taschenrechner ...“, Runde für Runde gefragt, „Wie „Viele Tage sollen angezeigt werden?“ zweimal, „Für welchen Ort ...?“ dreimal und „Wie heißt das Gibt es Video-Element ...?" zweimal). Die Eingabeaufforderungen tragen die Regel, und dieser Filter ist der deterministischer Backstop dafür: Wenn sich die Runde nur wiederholt, baut der Aufrufer statt Öffnen Sie das Popup erneut.

Hier gibt es bewusst KEINE Rundenbegrenzung – wie viele Runden sinnvoll sind, bleibt dem Ermessen überlassen Eingabeaufforderungsanweisungen („nehmen Sie alles, was existiert, aus dem vorhandenen Element heraus“), nicht eine feste Nummer.
