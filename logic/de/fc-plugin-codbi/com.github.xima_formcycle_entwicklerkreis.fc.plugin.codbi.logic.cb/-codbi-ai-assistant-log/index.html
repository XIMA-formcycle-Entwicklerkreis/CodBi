JPA-Entität für die Änderungsprotokolltabelle „codbi_ai_assistant_log“.

Nach jeder erfolgreichen AICodBiAssistant-Ausführungsaktion wird eine Zeile eingefügt. formChanges und workflowChanges enthält die strukturierte JSON-Beschreibung der auf das Formular und/oder angewendeten Änderungen den Workflow (siehe AiAssistantLog).
