MirrorAutoSync

object MirrorAutoSync

Automatische Hintergrundspiegelsynchronisation.

FORMCYCLE bietet Plugins, kein serverseitiges „Workflow-gespeichertes“ Ereignis und keinen Workflow-Designer Ressourcen-Hook, sodass ein im Workflow-Designer gespeicherter Quellpfad die reflektierenden Formulare nicht benachrichtigen kann direkt. Anstatt einen manuellen Klick zu erfordern, fragt dieser Watcher das persistente Workflow-Modell ab ein festes Intervall und lässt MirrorPushService.syncOutdatedReflectors nur das neu materialisieren Veraltete Spuren:

  • Die Inhaltsrevision des Quellpfads hat sich seit der letzten Materialisierung geändert, oder

  • Die reflektierende Spur enthält nicht mehr die Aktionsknoten der Quelle (Strukturdrift, z. B. die Der reflektierende Workflow-Designer hat sein veraltetes In-Memory-Modell über frisch erstellte Knoten gespeichert.

Wenn sich nichts geändert hat, ist das Häkchen ein kostengünstiger schreibgeschützter Durchgang (eine Abfrage für die „Mirror“-Knoten plus ein Source-Lane-Lesevorgang pro eindeutigem Quellpfad), sodass eine Leerlaufinstallation fast nichts kostet.

Einmal pro JVM von `CodbiFormResourcesPlugin.initialize` gestartet; Der Daemon-Thread blockiert nie abschalten. Wiederherstellungsansprüche werden durch die mit einem Zeitstempel versehene Markierung „Ausstehend“ geschützt MirrorMaterializedStore, sodass überlappende Ticks (oder Clusterknoten) nicht dieselbe Spur neu erstellen können zweimal.
