MirrorFormAccess

object MirrorFormAccess

Gemeinsame Zugriffsschicht zum Lesen des Inhalts eines anderen Formulars (eines „fremden“ Formulars), sodass ein Formular entsteht Das dort gespeicherte Element kann aus dem aktuell bearbeiteten Formular referenziert (gespiegelt) werden.

Dies ist der einzige Backend-Einstiegspunkt für den formularübergreifenden Elementzugriff und ist beabsichtigt wiederverwendbar durch:

  • das XMirror-Widget (rendert das referenzierte Element in der Designer-Vorschau und im Live-Modus bilden),

  • der Formularassistent (der Anforderungsbefehl „need_form_elements“ lädt hier die Elemente eines Formulars) und – die Designer-Servlet-Aktion, die die abhängigen Dropdown-Listen des Spiegel-Widgets füllt.

Die Plugin-API von Formcycle wird durch Reflektion verwendet (siehe de.xima.fc.api.APIProvider), sodass die Das Plugin funktioniert weiterhin über Patch-Releases hinweg, genau wie InstalledFormcycleElements bereits tut. Nur die Formular-*Modelltypen (XForm, XItem) werden direkt verwendet – sie sind Teil des stabiler Form-Renderer-Vertrag, mit dem jedes Widget-Plugin bereits kompiliert wird.
