mirroredElementReferenceMap

fun mirroredElementReferenceMap(userContext: Any?, sourceFormKey: String?, targetFormKey: String?): Map<String, String>

Referenzzuordnung von den Elementverweisen des Quell-Formulars zu ihren reflektierten Gegenstücke, die vom Workflow-Materializer verwendet werden, um kopierte Workflow-Knotenparameter neu zu verweisen („customParameters“) bei den gespiegelten Kopien.

Ein reflektierter Workflow-Pfad ist eine KOPIE des Quellpfads und viele Knotentypen verweisen auf das Formular ELEMENTE durch ihre technische ID/Namen innerhalb von „customParameters“ – z.B. FC_IMPORT_FORM_VALUE_FROM_XML speichert seine „XML-Quelle“ als „{“resource“:{“type“: „UPLOAD“, „identifier“: „“}}` und sein „xpathMapping“ benennen die Zielfelder nach ID, „FC_RETURN_FILE“/„FC_EMAIL.attachments“, Benennen Sie ein Upload-Feld und senden Sie es per E-Mail Körper verwenden „%field%“-Platzhalter. Wörtlich kopiert, benennen diese Verweise weiterhin die QUELLE Element, das in der spiegelnden Form nicht existiert – der Knoten zeigt dann ein LEERES Element an Picker in seinem Eigenschaftendialog und führt zur Ausführungszeit keine Aktion aus.

Die Zuordnung ist:

  • Quellelement NAME -> der NAMESPACED-Name der Kopie (<mirrorName>_<sourceName>, der Name des Entwurfszeitkopien UND das Live-Renderregister) und

  • Quellelement-ID -> die ID der Kopie (der Designer prägt eine neue).

Kopierte Elemente werden von der MIRRORED_CHILD_OWNER_PROPERTY der Designer-Materialisierung erkannt Stempel darauf; Ihr Namespace-Name wird mithilfe des Besitzers auf den Quellnamen reduziert Der eigene Name des Spiegels (mit einer Suffixübereinstimmung als Ersatz, wenn dies nicht aufgelöst werden kann).

Return

Eine leere Karte, wenn eines der Formulare nicht gelesen werden kann oder das reflektierende Formular keine Kopien enthält.
