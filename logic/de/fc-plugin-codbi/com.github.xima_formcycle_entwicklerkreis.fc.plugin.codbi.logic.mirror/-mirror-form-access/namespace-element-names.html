namespaceElementNames

fun namespaceElementNames(json: JSONObject, rootRef: String?, namePrefix: String?): Boolean

Stellt den Namen eines Elementunterbaums ein Präfix voran (das Element selbst und alle seine Nachkommen). mit namePrefix innerhalb des analysierten persistenten JSON – d. h. bevor der Teilbaum gerendert wird.

Dadurch funktionieren die gespiegelten SENDEN-TASTEN. Während ein Element gerendert wird, registriert sich FORMCYCLE seine Absendeschaltflächen in der Formularanforderungssitzung (xfc-pp-buttonmap, eingegeben von „Pair(buttonListName, buttonName)“ plus „xfc-pp-actionmap“, wenn die Submit-Action-Validierung erfolgt aktiviert) und eine spätere Übermittlung wird in genau diesen Karten nachgeschlagen: FormProcessUtil.decodeSubmittedXfAction → null → „Schaltflächenschlüssel … im aktuellen Formular nicht gefunden.“ Anfragesitzung – wurde das Formular zum Absenden manipuliert?“ → „Anfrage nicht akzeptiert.“

Bei der Registrierung werden die Namen des Elements verwendet, das gerendert wird. Spiegelung der QUELLE Das Element registriert daher die SOURCE-Namen und stellt nur das ausgegebene Markup voran (das ist was der Kunde übermittelt) führt dazu, dass Sitzung und Markup nicht übereinstimmen – jeder gespiegelte Klick stimmt nicht abgelehnt. Wenn Sie das Modell zunächst umbenennen, stimmen Modell, Markup und Sitzung überein, und zwei bleiben erhalten dass gespiegelte Tastenlisten auf identischen Tasten kollidieren.

IDs bleiben bewusst unangetastet: Die technische ID des Artikels ist die, die die persistenten Kopien haben Der Marker „data-xm-appendable“ und das Namespace-Validierungsmodell beziehen sich auf.

Return

„true“, wenn mindestens einer der Namen von namePrefix angewendet wurde.
