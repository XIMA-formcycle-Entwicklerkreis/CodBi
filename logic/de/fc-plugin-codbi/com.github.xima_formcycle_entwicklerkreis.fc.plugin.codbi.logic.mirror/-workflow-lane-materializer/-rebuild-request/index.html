RebuildRequest

data class RebuildRequest(val source: WorkflowLaneMaterializer.SourceLane, val laneParent: Any, val childrenToReplace: List<Any>, val targetWorkflowVersion: Any?, val syncEndpoint: Boolean = true)

Was vollständig abgelehnt und NEU ERSTELLT werden soll (Strukturdrift-Fallback). Im Gegensatz zu RewriteRequest (which überschreibt vorhandene ausgerichtete Knoten an Ort und Stelle), dies beschreibt einen Ersatz der gesamten Spur: der Lane-Container, dessen untergeordnete Elemente die Aktionsspur enthalten, und die genauen untergeordneten Elemente, die entfernt/neu erstellt werden sollen.

Parameters

laneParent

the WorkflowNode whose children collection forms the lane (a sibling „SEQUENCE“ des Mirror-Knotens oder das übergeordnete Element des Mirror-Knotens, wenn der Mirror der der Spur ist erstes Kind). Neue Knoten werden diesem Container neu zugeordnet.

childrenToReplace

the reflecting action nodes to delete and recreate from source.
