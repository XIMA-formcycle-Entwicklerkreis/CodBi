WorkflowMirrorAccess

object WorkflowMirrorAccess

Read-only access to the workflow paths (FORMCYCLE WorkflowTasks) of another form.

This is the workflow counterpart of MirrorFormAccess: the form Mirror references a form element from another form, the workflow Mirror node references a workflow path (trigger + node tree) from another form and exposes its current structure as a workflow result.

The path is always resolved live at execution time from the source project's active WorkflowVersion, so edits in the source workflow are reflected by the next execution. There is no pinned/versioned mode.

FORMCYCLE's plugin API (de.xima.fc.api.APIProvider) and JPA entities are used through reflection, keeping the plugin compatible across patch releases. The entity manager is obtained through de.xima.fc.jpa.context.EntityContextFactory, exactly like AICodBiAssistant.buildWorkflowStructureContext.
