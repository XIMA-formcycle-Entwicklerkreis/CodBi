abstract class CodBi

Basisklasse für alle CodBi-Komponenten.

Stellt einen gemeinsamen Logger bereit, der Nachrichten im Format [[ CodBi / idLogMessages ] ...Nachricht... ].

Unterklassen setzen idLogMessages auf ihren eigenen Subsystemnamen (z. B. „AI“, „Tesseract“, „LLAMA“) Identifizieren Sie die Protokollausgabe.
