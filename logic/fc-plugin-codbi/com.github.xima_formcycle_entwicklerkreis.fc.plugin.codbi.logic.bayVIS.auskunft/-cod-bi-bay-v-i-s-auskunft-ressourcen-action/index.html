CodBiBayVISAuskunftRessourcenAction

class CodBiBayVISAuskunftRessourcenAction : IPluginServletAction

Single nano-server proxy for every BayernPortal (BayVIS) REST v3 resource that the dedicated servlets (CodBiBayVISAuskunftBehoerdenverzeichnisAction, CodBiBayVISAuskunftBehoerdendetailsAction, CodBiBayVISAuskunftGebaeudedetailsAction, CodBiBayVISAuskunftAnsprechpartnerverzeichnisAction, CodBiBayVISAuskunftAnsprechpartnerdetailsAction) do not cover.

The dedicated servlets and their element placeholders stay untouched — this servlet only ADDS the resources documented at https://www.baybw-services.bayern.de/restapi.htm:

Unlike the dedicated servlets (whose element placeholders parse the XML default representation of the API) this servlet asks the portal for application/json, so the new element placeholders can parse the body with JSON.parse without guessing the XML envelope names.

Request headers:

  • Service (required): one of the whitelisted keys above — an unknown key is rejected, so the frontend can never call an arbitrary path with the plugin's credentials.

  • ID / ID2 / ID3 (optional, depending on the resource): the numeric path ids; they are percent-encoded and substituted into {id}, {id2} and {id3}.

  • Full (optional): true / false — forwarded as the full query parameter.

  • Gemeindekennziffer (optional): 8-digit official municipality key — forwarded as gemeindekennziffer.

Configuration Keys:

  • BayVIS_Benutzername: The username to use to log into the BayVIS-API.

  • BayVIS_Passwort: The password to use to log into the BayVIS-API.

  • BayVIS_UpdateCycle: Hours after which a cached result is re-requested.

  • BayVIS_CacheSize: Maximum number of cached responses the bounded LRU cache may hold before the least-recently-used entries are evicted (default DEFAULT_CACHE_SIZE, i.e. 256). Big enough to hold every whitelisted collection (the largest, /leistungsbeschreibungen, is multi-MB) plus many id-keyed detail records at once.

  • BayVIS_EP_Ressourcen: Optional base URL of the REST v3 API (default https://www.bayernportal-webservices.bayern.de/rest/allgemein/v3).
