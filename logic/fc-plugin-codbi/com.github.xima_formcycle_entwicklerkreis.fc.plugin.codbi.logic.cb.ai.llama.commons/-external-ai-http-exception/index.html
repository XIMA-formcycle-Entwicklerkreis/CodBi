class ExternalAiHttpException(val httpStatus: Int, val body: String) : RuntimeException

Thrown when an external OpenAI-compatible API returns a non-2xx HTTP status. Using a dedicated exception type allows callers to distinguish expected API-level errors (wrong model name, token limit, auth failure, …) from unexpected infrastructure failures and log them accordingly.
