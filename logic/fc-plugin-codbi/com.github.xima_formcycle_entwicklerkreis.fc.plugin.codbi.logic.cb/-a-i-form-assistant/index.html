AIFormAssistant

class AIFormAssistant : IPluginServletAction

AI Form Assistant — servlet that lets the form designer ask an AI to modify the current form structure.

Actions dispatched via the X-Action request header:

  • Models (GET): returns the list of available AI models as a JSON array of [{"id":"...","label":"..."}].

  • Run (POST): accepts prompt and persist form parameters, sends them to the selected model (identified by the X-Model header), and returns the modified IPersistJson as raw JSON.

Exposes the following endpoints through FORMCYCLE's HTTP stack:

GET   /plugin?name=CodBi_AIFormAssistant   (X-Action: Models)
POST  /plugin?name=CodBi_AIFormAssistant   (X-Action: Run, X-Model: )
