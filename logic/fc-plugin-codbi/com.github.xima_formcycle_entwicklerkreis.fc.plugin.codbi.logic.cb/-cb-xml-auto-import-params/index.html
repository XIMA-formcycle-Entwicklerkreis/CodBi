CbXmlAutoImportParams

object CbXmlAutoImportParams

Normalises the AI's node parameters for the CodBi cbXMLAutoImport workflow node.

The node itself needs no per-field mapping (it imports every value whose field exists in the form); the only field list it knows is the EXCLUSION list. Models emit that list in many shapes — an array of names, an array of {name} objects, a comma/newline separated string or a name→value map — so it is normalised here before it reaches the node's custom parameters.
