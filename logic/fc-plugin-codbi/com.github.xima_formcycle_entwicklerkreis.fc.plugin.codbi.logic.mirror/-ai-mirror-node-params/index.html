AiMirrorNodeParams

object AiMirrorNodeParams

Builds the customParameters JSON of the CodBi workflow Mirror node for an AI-generated workflow.

The Mirror node (WorkflowNode.type = "Mirror", see MirrorNodePlugin) stores the source form (project-<id>) and the numeric id of one of that form's workflow paths (WorkflowTask). The language model never sees foreign workflow-path ids and it must not invent them, so it emits only what it can actually know:

{"nodeType":"Mirror","nodeParams":{"sourceForm":"project-<id>"|"<form title>",
 "pathName":"<exact name of the source workflow path>", ...}}

input (any of)resolved to

sourceFormName / formName / formTitlesourceFormName = form title
pathId (numeric)pathId (used as given)
pathName / sourcePathName / path / sourcePathpathId + pathName resolved

Resolution failures never abort the workflow build: the node is written with whatever was resolvable (so the designer shows it and the user can pick the path there) and the problem is logged.
