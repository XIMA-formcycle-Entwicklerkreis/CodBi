MirrorAutoSync

object MirrorAutoSync

Automatic, background Mirror synchronisation.

FORMCYCLE offers plugins no server-side "workflow saved" event and no workflow-designer resource hook, so a source path saved in the workflow designer cannot notify the reflecting forms directly. Instead of requiring a manual click, this watcher polls the persisted workflow model at a fixed interval and lets MirrorPushService.syncOutdatedReflectors re-materialize only the lanes that are out of date:

  • the source path's content revision changed since the last materialization, or

  • the reflecting lane no longer contains the source's action nodes (structural drift, e.g. the reflecting workflow designer saved its stale in-memory model over freshly created nodes).

When nothing changed the tick is a cheap read-only pass (one query for the Mirror nodes plus one source-lane read per distinct source path), so an idle installation costs almost nothing.

Started once per JVM from `CodbiFormResourcesPlugin.initialize`; the daemon thread never blocks shutdown. Rebuild claims are guarded by the timestamped pending marker in MirrorMaterializedStore, so overlapping ticks (or cluster nodes) cannot recreate the same lane twice.
