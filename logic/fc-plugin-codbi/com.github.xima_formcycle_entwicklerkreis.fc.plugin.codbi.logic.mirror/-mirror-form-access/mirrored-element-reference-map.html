mirroredElementReferenceMap

fun mirroredElementReferenceMap(userContext: Any?, sourceFormKey: String?, targetFormKey: String?): Map<String, String>

Reference map from the source form's element references to their reflected counterparts, used by the workflow materializer to re-point copied workflow-node parameters (customParameters) at the mirrored copies.

A reflected workflow path is a COPY of the source path, and many node types reference form ELEMENTS by their technical id/name inside customParameters — e.g. FC_IMPORT_FORM_VALUE_FROM_XML stores its “XML-Quelle” as {"resource":{"type":"UPLOAD","identifier":"<upload field>"}} and its xpathMapping names the target fields by id, FC_RETURN_FILE/FC_EMAIL.attachments name an upload field, and mail bodies use [%field%] placeholders. Copied verbatim, those references keep naming the SOURCE element, which does not exist in the reflecting form — the node then shows an EMPTY element picker in its properties dialog and does nothing at execution time.

The mapping is:

  • source element NAME -> the copy's NAMESPACED name (<mirrorName>_<sourceName>, the name the design-time copies AND the live render register), and

  • source element ID -> the copy's ID (the designer mints a new one).

Copied items are recognized by the MIRRORED_CHILD_OWNER_PROPERTY the designer materialization stamps on them; their namespaced name is stripped back to the source name using the owning Mirror's own name (with a suffix match as fallback when that cannot be resolved).

Return

an empty map when either form cannot be read or the reflecting form holds no copies.
