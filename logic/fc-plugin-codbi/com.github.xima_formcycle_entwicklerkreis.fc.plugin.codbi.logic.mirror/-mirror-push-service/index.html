MirrorPushService

object MirrorPushService

Phase-2d shared service that pushes the latest SOURCE lane into the registered REFLECTING lanes.

Extracted from MirrorNodePlugin.pushToReflectors so the same push core can be invoked both from the reflecting-side Mirror node (Option A1) and — the sink of this redesign — from the backend MirrorPush servlet action that is triggered by the frontend designer save hook immediately after a SOURCE form/workflow is published.

The loop is params-free: it only needs a user context, a source (formKey, pathId/name) and the reflectors to fill. After each successful rebuild it mirrors the stored materialized revision for the reflecting target so the reflecting lazy path becomes a no-op (convergence guard), and clears any pending structural-rebuild marker so a subsequent reflecting trigger does not double-rebuild.
