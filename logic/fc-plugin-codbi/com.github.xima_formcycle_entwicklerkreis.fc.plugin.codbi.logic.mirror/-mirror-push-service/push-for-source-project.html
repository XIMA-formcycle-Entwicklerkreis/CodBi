pushForSourceProject

fun pushForSourceProject(userContext: Any?, sourceProjectId: Long): String

Entry point of the source-save hook (X-Action: MirrorPush): pushes the latest lane of every Mirror node that mirrors sourceProjectId into its reflecting path.

The reflectors are resolved live from the persisted workflow model (WorkflowMirrorAccess.discoverReflectors) and merged with the runtime registry rows of the same project (MirrorMaterializedStore.reflectorsOfSourceProject). The live discovery is what makes the push work the FIRST time — the registry alone is only filled once a reflecting Mirror node has EXECUTED, which never happens for a freshly configured reflective path that still consists of nothing but the Mirror node.

Return

a human-readable status summary for logging / the servlet response.
