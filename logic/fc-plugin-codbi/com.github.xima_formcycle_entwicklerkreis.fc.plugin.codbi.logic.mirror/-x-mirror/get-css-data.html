getCssData

open override fun getCssData(): String

CSS painted with the designer (and the published form): paints ICON_SVG for the .ico-fc-XMirror class returned by getIcon.

FORMCYCLE renders an icon returned as ico-fc-* as <i class="ico-fc-*"> (a CSS class, never a URL) — so we must paint it here. A data URI is used because a resource URL cannot be built server-side (the servlet context path is not known to the widget), and a relative URL resolves against the designer's deep page path and 404s.

The layered drop-shadows add the "cool blur" glow around the technical arrow (the arrow also carries an out-of-focus beam stroke, see ICON_SVG).
