XmlAutoImport

object XmlAutoImport

Reads a stored form-state XML file and turns it into "write THIS value into THAT form field" instructions — without any manually configured XPath mapping.

FORMCYCLE's own FC_IMPORT_FORM_VALUE_FROM_XML node only writes the fields listed in its xpathMapping property ("Zu setzende Werte"); every other value in the file is ignored. This planner is the counterpart for the CodBi cbXMLAutoImport node: it discovers the values in the file on its own and matches them against the fields the form actually has.

Two XML shapes are recognized:

  1. formcycle form-data XML (FC_EXPORT_TO_XML, root tag xfc-data): every <field name="…"> element provides one field; the value lives in <plainValue> and/or in <values><value index="…">…</value></values> (repetitions).

  2. generic XML: every leaf element whose tag name matches a form field uses its text as the value; an attribute whose NAME is a form field uses the attribute value, an attribute whose VALUE is a form field (e.g. <field name="firstName">) uses the element text.
