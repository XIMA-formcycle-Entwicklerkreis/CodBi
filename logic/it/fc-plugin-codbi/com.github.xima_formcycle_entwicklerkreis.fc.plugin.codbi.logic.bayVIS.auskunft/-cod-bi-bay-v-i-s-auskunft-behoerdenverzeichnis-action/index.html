CodBiBayVISAuskunftBehoerdenverzeichnisAction

class CodBiBayVISAuskunftBehoerdenverzeichnisAction : IPluginServletAction

Questo servlet funge da nano server per passare la richiesta da un modulo utilizzando CodBi insieme al file Le funzionalità relative a BayVIS all'API BayVIS in questo modo impediscono l'esposizione delle credenziali.

Chiavi di configurazione:

  • BayVIS_Benutzername: il nome utente da utilizzare per accedere all'API BayVIS.

  • BayVIS_Passwort: la password da utilizzare per accedere a BayVIS-API.

  • BayVIS_EP_Behoerdenverzeichnis: specifica facoltativa di dove si trova l'endpoint per il recupero del è possibile trovare la directory delle autorità.
