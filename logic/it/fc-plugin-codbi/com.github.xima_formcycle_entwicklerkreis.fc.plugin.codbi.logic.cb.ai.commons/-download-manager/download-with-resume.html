downloadWithResume

fun downloadWithResume(url: String, targetFile: File, label: String, expectedSha256: String? = null): Boolean

Scarica un file da url a targetFile con il supporto del Riprendi intervallo HTTP.

Se il file di destinazione esiste già parzialmente (ad esempio da un precedente download interrotto), esso invia un'intestazione Range: bytes=<existing>- in modo che il server continui da dove si era interrotto. Se il server non supporta le richieste Range (nessuna risposta 206), il file viene scaricato nuovamente da l'inizio.

Return

"true" se il download è riuscito (o il file esisteva già a dimensione intera).

Il metodo crea anche un file marcatore (<targetFile>.complete) una volta completato con successo, che viene utilizzato per controllare rapidamente.

Parameters

url

The URL to download.

targetFile

The destination file.

label

A human-readable label for log messages (e.g., "GGUF model").

expectedSha256

Optional lowercase hex SHA-256 digest. When non-null, the downloaded file viene verificato al termine del trasferimento. In caso di mancata corrispondenza il file viene eliminato e lo è "false". restituito. I download già completati (marcatore presente) saltano la nuova verifica.
