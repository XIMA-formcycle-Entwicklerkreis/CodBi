execute

open override fun execute(params: IPluginServletActionParams): IPluginServletActionRetVal

Se attivato dalla proprietà del plugin CodBi Active_AI contenente OCR, utilizza AI bidello per archiviare le immagini che hanno un ID (se trasmesso nell'intestazione X-OCR-Image-ID) e estrae tutto il testo dalle immagini trasmesse o tramite X-OCR-Image-ID specificate.

Opzioni X-Mode (senza distinzione tra maiuscole e minuscole):

  • stampa (impostazione predefinita): estrazione di testo semplice: estrae tutto il testo dalle immagini.

  • extract: estrae il testo dalle immagini e restituisce solo le parti che corrispondono alla regex modello specificato nell'intestazione X-Pattern.

  • verifica: estrae il testo dalle immagini e controlla se il testo corrisponde al modello regex specificato nell'intestazione X-Pattern.

  • estrai campi: estrae il testo dalle immagini e applica più modelli regex dal file Intestazione X-FieldPatterns (array JSON) per estrarre i valori dei campi.

Return

Un IPluginServletActionRetVal corretto.

Parameters

params

As provided by the formcycle environment.
