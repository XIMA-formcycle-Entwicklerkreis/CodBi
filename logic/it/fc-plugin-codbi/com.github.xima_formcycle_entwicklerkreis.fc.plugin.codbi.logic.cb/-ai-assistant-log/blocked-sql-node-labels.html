blockedSqlNodeLabels

fun blockedSqlNodeLabels(workflowChanges: JsonArray?): List<String>

Estrae le etichette di tutti i nodi del flusso di lavoro la cui voce del registro delle modifiche è stata contrassegnata come bloccata istruzione SQL distruttiva (params.blockedSql == true). Utilizzato dal frontend per eseguire il rendering di un file icona/messaggio di errore e per aprire automaticamente il registro delle modifiche dopo un'esecuzione SQL distruttiva generata.

Return

Le etichette dei nodi (FC_SQL_STATEMENT "<nome>"), distinte e ordinate.

Parameters

workflowChanges

The workflow change description (the nodeLog array produced by AICodBiAssistant.runWorkflowCreation), ogni voce { nome, trigger, elementi, stato }.
