computeAppliedWorkflowItems

fun computeAppliedWorkflowItems(nodeLog: JsonArray?): JsonObject?

Costruisce la metà del FLUSSO DI LAVORO del payload "elementi" archiviato con una voce del registro delle modifiche: una ripristinabile nodo del flusso di lavoro per PERCORSO del flusso di lavoro creato (attività), ciascuno contenente il WorkflowTaskSpec COMPLETO Generato dall'intelligenza artificiale, in modo che il registro delle modifiche possa ricreare quel percorso in un secondo momento senza un'altra inferenza.

Le specifiche sono allegate ai percorsi del registro dei nodi da "AICodBiAssistant.runWorkflowCreation" in la chiave privata _spec (non fanno parte della modifica DESCRIZIONE — vale la descrizione solo etichette). Questo metodo li ESTRAE nella forma del payload { "workflow": { "nodes": [ { "name": "<task name>", "spec": {…} } ] } } e, nello stesso passaggio, RIMUOVE il privato "_spec" da ogni percorso, quindi non viene memorizzato in "workflow_changes" (che viene restituito al file client e utilizzato per l'albero) né duplicato.

Le operazioni di rimozione/sostituzione non riportano _spec e pertanto non sono riapplicabili (non esiste elemento da "rigenerare"). Restituisce "null" quando nessun percorso contiene una specifica.
