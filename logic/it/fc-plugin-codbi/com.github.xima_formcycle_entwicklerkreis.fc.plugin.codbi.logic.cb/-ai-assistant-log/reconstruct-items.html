fun reconstructItems(formChanges: JsonObject?): JsonObject?

Ricostruisce gli elementi ripristinabili da una modifica DESCRIZIONE (form_changes) — l'unico elemento dati trasporta una voce registrata prima della colonna "elementi".

attributesSet contiene ogni proprietà che l'IA ha effettivamente IMPOSTATO sull'elemento (nome + valore + tipo) e classesSet le sue classi CSS di classe standard, quindi l'elemento è ricostruibile da className + name + quelle proprietà. Solo ciò che l'IA NON ha impostato (valori predefiniti di Formcycle) e gli annidamenti (il chiamante ritorna all'ultima pagina) sono sconosciuti.

Restituisce la forma computeAppliedItems con ciascuna voce contrassegnata come "reconstructed":true` oppure "null" quando la descrizione non contiene alcun elemento (pura chat/voci di sole variabili).
