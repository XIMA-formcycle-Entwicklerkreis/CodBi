ClarificationQuestionFilter

object ClarificationQuestionFilter

Applica UNA regola della richiesta di chiarimento nel codice: una domanda non deve mai essere posta due volte.

Un piccolo modello locale tende a chiedere nuovamente un dettaglio che ha già ricevuto o l'elemento target contiene già (osservato: "Welche Art von Taschenrechner ..." chiesto giro dopo giro, "Wie viele Tage sollen angezeigt werden?" due volte, "Für welchen Ort ...?" tre volte e "Wie heißt das vorhandene Video-Element ...?" due volte). Le istruzioni portano la regola e questo filtro è il backstop deterministico per questo: quando il round si ripete, il chiamante COSTRUISCE invece di aprendo nuovamente il popup.

Non c'è deliberatamente NESSUN limite di round qui: quanti round sono sensati è un giudizio chiamato the le istruzioni rapide creano ("prendi tutto ciò che esiste dall'elemento esistente"), non un valore fisso numero.
