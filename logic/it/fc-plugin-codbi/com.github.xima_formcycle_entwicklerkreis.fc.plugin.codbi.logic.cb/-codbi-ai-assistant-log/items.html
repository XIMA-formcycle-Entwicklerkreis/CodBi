var items: String?

JSON che contiene gli elementi del modulo COMPLETAMENTE risolti/le specifiche del nodo del flusso di lavoro create o modificate da questa esecuzione, ognuno con il contenitore in cui vive: {"form":{"items":[{item,parent,index}],"removed":[{item,parent}]},"workflow":{"nodes":[{spec,trigger}]}}.

formChanges/workflowChanges contengono solo SOMMARI (nomi, attributi modificati), ovvero non abbastanza per ricostruire qualcosa: questa colonna è ciò che consente al registro delle modifiche di riapplicare una voce the CURRENT form/workflow without another inference (see AiAssistantLog.computeAppliedItems and AICodBiAssistant.handleApplyLogEntry). null for entries recorded before the column existed (those can only be re-applied with AI support).
