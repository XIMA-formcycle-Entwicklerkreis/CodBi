Entità JPA per la tabella "codbi_ai_log_sensitive_check".

Una riga viene archiviata ogni volta che un utente seleziona la casella di controllo Ignora in corrispondenza della occorrenza di un elemento sensibile in il registro delle modifiche AI, quindi il controllo è attribuibile e sopravvive ai ricaricamenti della pagina/ad altri designer sessioni. Una riga è digitata da (ID voce di registro, nome elemento, login utente): l'eliminazione della riga deseleziona di nuovo.
