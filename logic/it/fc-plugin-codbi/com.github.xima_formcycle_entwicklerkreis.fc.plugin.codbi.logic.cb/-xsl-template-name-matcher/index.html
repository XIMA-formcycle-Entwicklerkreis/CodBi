XslTemplateNameMatcher

object XslTemplateNameMatcher

Corrisponde al NOME del modello di trasformazione che l'utente ha scritto in prosa rispetto ai modelli XSL che esistono realmente per il cliente.

Un utente nomina il modello all'interno di una frase ("… und zuvor mit XXX transformiert werden", "mit der XSLT-Vorlage XXX", "trasformato da XXX"), quindi il nome raggiunge il build pass nell'ortografia in prosa — non identico in byte a quello memorizzato. La corrispondenza deve quindi tollerare maiuscole e minuscole, spazi, caratteri di sottolineatura, trattini, dieresi/varianti ß e un .xsl/.xslt finale e dovrebbero accettare un chiaro parziale corrispondenza ("Anschriftenreport" → "Anschriften Report 2024").

Regola di sicurezza: una corrispondenza UNICA viene accettata, una AMBIGUA non viene mai indovinata: il chiamante mantiene il nodo senza un modello (XML grezzo) invece di trasformarsi silenziosamente con il foglio di stile sbagliato.
