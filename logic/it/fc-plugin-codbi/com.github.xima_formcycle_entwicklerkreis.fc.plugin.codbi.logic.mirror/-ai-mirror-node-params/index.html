AiMirrorNodeParams

object AiMirrorNodeParams

Crea il JSON "customParameters" del nodo Mirror del flusso di lavoro CodBi per un oggetto generato dall'intelligenza artificiale flusso di lavoro.

Il nodo Mirror (WorkflowNode.type = "Mirror", vedere MirrorNodePlugin) memorizza il modulo sorgente (project-<id>) e l'id numerico di uno dei percorsi del flusso di lavoro di quel modulo (WorkflowTask). IL il modello linguistico non vede mai ID di percorsi di flusso di lavoro estranei e non deve inventarli, quindi emette solo cosa può effettivamente sapere:

{"nodeType":"Mirror","nodeParams":{"sourceForm":"project-<id>"|"<form title>",
 "pathName":"<exact name of the source workflow path>", ...}}

Gli errori di risoluzione non interrompono mai la creazione del flusso di lavoro: il nodo viene scritto con qualunque cosa fosse risolvibile (così il progettista lo mostra e l'utente può scegliere il percorso lì) e il problema è registrato.
