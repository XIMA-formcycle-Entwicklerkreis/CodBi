MirrorFormAccess

object MirrorFormAccess

Livello di accesso condiviso per leggere il contenuto di un altro modulo (un modulo “estraneo”) in modo che un form l'elemento memorizzato lì può essere referenziato (mirrorato) dal modulo attualmente modificato.

Questo è l'unico punto di ingresso del backend per l'accesso agli elementi cross-form ed è intenzionale riutilizzabile da:

  • il widget XMirror (renderizza l'elemento di riferimento nell'anteprima del designer e nel live modulo),

  • l'assistente del modulo (il comando di richiesta need_form_elements carica qui gli elementi di un modulo), e

  • l'azione servlet del designer che popola i menu a discesa dipendenti del widget Mirror.

L'API del plug-in di Formcycle viene utilizzata attraverso la riflessione (vedere de.xima.fc.api.APIProvider), quindi il plugin continua a funzionare tra i rilasci delle patch, esattamente come già InstalledFormcycleElements. fa. Solo i tipi di modulo modello (XForm, XItem) vengono utilizzati direttamente: fanno parte del contratto stabile di rendering del modulo rispetto al quale ogni plug-in widget è già compilato.
