mirroredElementReferenceMap

fun mirroredElementReferenceMap(userContext: Any?, sourceFormKey: String?, targetFormKey: String?): Map<String, String>

La mappa di riferimento dall'elemento del modulo source fa riferimento al loro riflesso controparti, utilizzate dal materializzatore del flusso di lavoro per ri-puntare i parametri del nodo del flusso di lavoro copiati ("customParameters") nelle copie specchiate.

Un percorso del flusso di lavoro riflesso è una COPIA del percorso di origine e molti tipi di nodo fanno riferimento al modulo ELEMENTI tramite il loro ID/nome tecnico all'interno di "customParameters" — ad es. FC_IMPORT_FORM_VALUE_FROM_XML memorizza il suo "XML-Quelle" come {"resource":{"type":"UPLOAD","identifier":"<campo di caricamento>"}} e il suo xpathMapping nominano il campi di destinazione in base all'ID, al nome "FC_RETURN_FILE"/FC_EMAIL.attachments, a un campo di caricamento e all'e-mail i corpi utilizzano i segnaposto "%field%". Copiati alla lettera, questi riferimenti continuano a nominare la FONTE elemento, che non esiste nella forma riflettente: il nodo quindi mostra un elemento EMPTY selettore nella finestra di dialogo delle proprietà e non fa nulla in fase di esecuzione.

La mappatura è:

  • elemento sorgente NOME -> il nome NAMESPACED della copia (<mirrorName>_<sourceName>, il nome copie in fase di progettazione E il registro di rendering live) e

  • ID dell'elemento sorgente -> ID della copia (il designer ne conia uno nuovo).

Gli elementi copiati vengono riconosciuti da MIRRORED_CHILD_OWNER_PROPERTY la materializzazione del designer timbri su di loro; il loro nome nello spazio dei nomi viene ridotto al nome di origine utilizzando il proprietario Il nome proprio del mirror (con una corrispondenza del suffisso come fallback quando il problema non può essere risolto).

Return

una mappa vuota quando una delle forme non può essere letta o la forma riflettente non contiene copie.
