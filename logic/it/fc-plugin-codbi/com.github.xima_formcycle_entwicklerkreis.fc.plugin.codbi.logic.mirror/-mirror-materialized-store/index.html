MirrorMaterializedStore

object MirrorMaterializedStore

Archivio persistente di fase 2 per l'ultima revisione del codice sorgente materializzata di ogni mirror (target versione del flusso di lavoro + percorso di origine). Riutilizza la tabella chiave-valore generica del plugin codbi_local_apidoc (entità CodbiLocalApidoc) in modo che la risincronizzazione lenta possa decidere se la fonte è cambiata senza toccare la corsia riflettente quando non lo ha fatto.

Formato chiave: "codbi.mirror.materialized..." Valore: la revisione del contenuto del percorso di origine (un Int) come stringa. Quando il valore è assente la corsia era mai materializzato -> è necessaria una nuova sincronizzazione.

Tutte le operazioni di lettura/scrittura utilizzano il proprio EntityManager + transazione tramite CodbiEntities.entityManagerFactory (schema gestito da Formcycle), esattamente come il Local API Doc / Archivi di log AI, quindi non toccano mai la sessione dell'esecutore del flusso di lavoro.
