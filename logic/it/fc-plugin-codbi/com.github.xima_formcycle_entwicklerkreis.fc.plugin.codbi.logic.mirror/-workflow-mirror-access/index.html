WorkflowMirrorAccess

object WorkflowMirrorAccess

Accesso in sola lettura ai percorsi del flusso di lavoro (FORMCYCLE WorkflowTasks) di un altro modulo.

Questa è la controparte del flusso di lavoro di MirrorFormAccess: il modulo Mirror fa riferimento a un elemento del modulo da un altro modulo, il nodo Mirror del flusso di lavoro fa riferimento a un percorso del flusso di lavoro (trigger + albero dei nodi) da un altro modulo ed espone la sua struttura corrente come risultato del flusso di lavoro.

Il percorso viene sempre risolto in tempo reale al momento dell'esecuzione dal progetto di origine attivo "WorkflowVersion", quindi le modifiche nel flusso di lavoro di origine si riflettono nell'esecuzione successiva. C'è nessuna modalità bloccata/con versione.

L'API plugin di FORMCYCLE (de.xima.fc.api.APIProvider) e le entità JPA vengono utilizzate tramite riflessione, mantenendo il plugin compatibile tra i rilasci delle patch. Viene ottenuto il gestore dell'entità tramite de.xima.fc.jpa.context.EntityContextFactory, esattamente come "AICodBiAssistant.buildWorkflowStructureContext".
