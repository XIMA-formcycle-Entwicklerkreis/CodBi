getCssData

open override fun getCssData(): String

CSS dipinto con il designer (e il modulo pubblicato): dipinge ICON_SVG per il Classe .ico-fc-XMirror restituita da getIcon.

FORMCYCLE esegue il rendering di un'icona restituita come ico-fc-* come <i class="ico-fc-*"> (una classe CSS, mai un URL) - quindi dobbiamo dipingerlo qui. Viene utilizzato un URI di dati perché non è possibile creare un URL di risorsa lato server (il percorso del contesto servlet non è noto al widget) e viene risolto un URL relativo contro il percorso profondo della pagina del designer e i 404.

Le "ombre esterne" stratificate aggiungono il bagliore "sfocato" attorno alla freccia tecnica (anche la freccia comporta un tratto del raggio fuori fuoco, vedere ICON_SVG).
