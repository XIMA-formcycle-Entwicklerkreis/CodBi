XmlAutoImport

object XmlAutoImport

Legge un file XML dello stato del modulo memorizzato e lo trasforma in "scrivi QUESTO valore in QUEL campo del modulo" istruzioni: senza alcuna mappatura XPath configurata manualmente.

Il nodo FC_IMPORT_FORM_VALUE_FROM_XML di FORMCYCLE scrive solo i campi elencati nel suo Proprietà xpathMapping ("Zu setzende Werte"); ogni altro valore nel file viene ignorato. Questo planner è la controparte del nodo CodBi cbXMLAutoImport: scopre i valori nel file file da solo e li confronta con i campi effettivamente presenti nel modulo.

Vengono riconosciute due forme XML:

  1. formcycle form-data XML (FC_EXPORT_TO_XML, tag root xfc-data): ogni <campo name="…"> l'elemento fornisce un campo; il valore risiede in "" e/o in <values><value indice="…">…</value></values> (ripetizioni).

  2. XML generico: ogni elemento foglia il cui nome tag corrisponde a un campo modulo utilizza il suo testo come file valore; un attributo il cui NOME è un campo modulo utilizza il valore dell'attributo, un attributo il cui VALUE è un campo modulo (ad esempio <field name="firstName">) utilizza l'elemento testo.
