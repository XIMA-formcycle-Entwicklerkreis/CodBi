XmlImportOptions

object XmlImportOptions

Fornisce gli elenchi di opzioni dietro la vista designer cbXMLAutoImport.

Gli elenchi vengono esposti tramite il servlet del plugin, quindi la visualizzazione delle proprietà non necessita del supporto JSF fagiolo. Ogni metodo risponde con [{"value":"…","label":"…"}]:

  • caricamenti: elementi di caricamento file del modulo, valore = nome dell'elemento tecnico,

  • risorse — file della gestione dei file del modulo (ProjektRessource), value = uuid,

  • nodi: nodi del flusso di lavoro della versione del flusso di lavoro attiva che può produrre un file, valore = nodo uuid,

  • campi - elementi del modulo che possono contenere un valore importato (utilizzato dal "Nicht zu setzende Werte" select), "valore" = nome dell'elemento tecnico.
