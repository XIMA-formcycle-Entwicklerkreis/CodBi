Resource

class Resource : IPluginServletAction

Questo servlet recupera un modulo di risorsa all'interno del suo JAR o da una directory di override esterna.

Il parametro Path-URL specifica anche il percorso all'interno del JAR da cui recuperare il file il nome del file.

Se non è specificato alcun percorso, verrà utilizzato quanto segue: /com/github/xima_formcycle_entwicklerkreis/fc/plugin/codbi/Symbol_CodBi.svg.

Override esterno

Se è impostata la proprietà di sistema CodBi_ExternalResourceDir o la proprietà del plugin ExternalResourceDir è configurato, il servlet controlla prima quella directory prima di cadere ritorno al percorso di classe. Ciò consente l'aggiornamento delle risorse (ad esempio TinyMCE) in fase di esecuzione senza ridistribuire il JAR.
