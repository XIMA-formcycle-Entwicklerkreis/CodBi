CHAINED NODES ("chainedNodes" field) — For sequential actions where the second action processes the first action's output (e.g. decode Base64 then download the result), add a "chainedNodes" array inside a single task spec. Each entry has "nodeType" and "nodeParams". Use "%prev%" in chained node's nodeParams to reference the preceding node's UUID and "%sourceTaskUuid%" for the task UUID.
