Overview

LLAMA.kt has been significantly improved through decomposition. The class now focuses on orchestration and delegates platform detection, download/extraction, HTTP transport, and process lifecycle concerns to dedicated collaborators: PlatformDetector, DownloadManager, LlamaHttpClient, and LlamaProcessManager.

Strengths

The refactor substantially improved separation of concerns and readability versus the previous monolithic version.
Delegate instances are lazily initialized and consistently wired through a shared logging function, which keeps diagnostics coherent.
Binary selection logic remains robust (CPU/CUDA/Vulkan), while extraction and resumable download behavior are kept reusable in DownloadManager.
Process startup still exposes clear runtime diagnostics (resolved threads, GPU layer strategy, slot count, model details).
Lifecycle behavior in initialize and shutdown is straightforward and preserves backward compatibility with existing plugin properties.

Weaknesses & Risks

Restart contract remains incomplete. restartServer() still returns false in the base class and depends on subclass override discipline.
Recommendation: make restartServer() abstract or enforce override with a clear failure if not implemented.
Global singleton ports remain. activeServerPort and activeThinkingServerPort are static shared state and can cause conflicts if multiple LLAMA instances run in one JVM.
Recommendation: move routing state to instance-managed registries or one authoritative runtime coordinator.
Argument parsing is still fragile. AI_LLAMA_ENGINE_ServerArgs uses split(" "), which breaks quoted values and paths with spaces.
Recommendation: parse with a quote-aware tokenizer or define a delimiter-based format for arguments.
Qwen template file is still written next to the binary. This can fail on read-only deploy paths and mixes mutable runtime artifacts into binary directories.
Recommendation: write template files to a writable runtime directory under plugin data.

Priority Recommendations

  1. Finalize the restart contract (abstract or enforced override).
  2. Replace static active-port globals with instance-safe routing state.
  3. Fix quote-aware parsing of AI_LLAMA_ENGINE_ServerArgs.
  4. Move Qwen template output to a writable runtime location.
  5. Add focused tests for port conflict fallback, restart path, and bad argument inputs.
