Assessment v2: DownloadManager.kt

Date: March 14, 2026 | Branch: Designer_Interface | Repository: CodBi-Dev
File: src/main/kotlin/com/github/xima_formcycle_entwicklerkreis/fc/plugin/codbi/logic/cb/ai/commons/DownloadManager.kt

Overview

Focused utility for resumable binary/model downloads and safe archive extraction. The class is cohesive and production-oriented.

Strengths

Robust resume implementation with marker-file shortcut and HTTP 206 handling.
Redirect and partial-download logic is practical and operationally friendly.
Zip extraction has canonical-path checks that correctly defend against Zip Slip.
Tar extraction performs a traversal pre-scan and reports extraction failures via logs.

Risks

Redirect recursion has no max hop count.
Add a redirect depth guard to prevent looped redirects from hanging startup.
Tar traversal check with contains("..") is coarse and can miss normalized path edge cases.
Use path normalization plus canonical target-prefix validation for each tar entry.
External tar dependency can fail in locked-down or minimal runtime environments.
Detect tar availability early and fail fast with explicit remediation guidance.

Verdict

Well-implemented and significantly safer than average download/extract helpers. Most remaining work is edge-case hardening.
