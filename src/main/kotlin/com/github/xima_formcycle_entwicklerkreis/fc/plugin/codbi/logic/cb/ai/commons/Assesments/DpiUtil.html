Overview

DpiUtil is a compact utility for reading/writing image DPI metadata with practical PNG/JPEG support and a safe default fallback.

Strengths

Clean single-purpose design and low coupling.
Good resilience: returns a deterministic default DPI when metadata is missing or parsing fails.
Extraction logic is shared across file and byte-array paths, minimizing drift risk.
PNG write path explicitly preserves DPI metadata for downstream OCR quality.

Risks

Utility logs are branded to Tesseract context, reducing portability semantics for broader use.
Recommendation: use neutral logger messages or inject context-specific prefixes from callers.
Format-specific metadata handling may miss uncommon encoder variants.
Recommendation: add tests for edge metadata layouts and explicitly document supported formats.

Verdict

Strong utility extraction with reliable behavior; only small generalization and test-hardening opportunities remain.
