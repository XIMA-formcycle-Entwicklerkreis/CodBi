Assessment v2: LlamaHttpClient.kt

Date: March 14, 2026 | Branch: Designer_Interface | Repository: CodBi-Dev
File: src/main/kotlin/com/github/xima_formcycle_entwicklerkreis/fc/plugin/codbi/logic/cb/ai/commons/LlamaHttpClient.kt

Overview

Small transport client with sync POST and SSE streaming support for local llama.cpp endpoints.

Strengths

Clean API and strong single responsibility.
Improved diagnostics: body-read failures now preserve exception class and message.
SSE parser explicitly documents framing assumptions and logs unexpected SSE fields.
Default port indirection via lambda avoids stale port after restart.

Risks

No built-in retry for transient loopback errors during server warm-up.
Add optional short retry window for connection refused/timeouts in startup race windows.
SSE parser still ignores multiline data: event aggregation semantics from full SSE spec.
If compatibility scope expands beyond llama.cpp, add full SSE event assembly support.

Verdict

A strong utility class with recent correctness and observability improvements. Remaining gaps are mostly future-proofing concerns.
