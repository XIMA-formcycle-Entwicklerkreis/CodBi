Overview

Shared stateless detector for platform, GPU backend, and CPU core information used by server launch flows.

Strengths

Good isolation as a reusable singleton utility.
Timeout handling for external probes avoids blocking startup indefinitely.
Fallback logic is explicit and consistent when tools are unavailable.
Recent logging improvements provide concrete diagnostic details for missing binaries.

Risks

Method name detectPhysicalCores can be misleading on Linux because nproc --all may return logical CPUs.
Clarify method semantics or implement true physical-core detection per platform.
macOS always maps to GpuBackend.NONE while still using GPU via Metal, which may confuse operational metrics.
Consider introducing a METAL enum state for clearer capability reporting.

Verdict

A reliable foundational utility with sensible timeouts and fallbacks; remaining issues are mainly semantics and observability clarity.
