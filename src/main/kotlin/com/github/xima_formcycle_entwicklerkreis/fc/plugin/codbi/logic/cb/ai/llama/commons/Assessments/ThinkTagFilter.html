Overview

Filters or normalizes think-tag content in model output so downstream consumers receive expected response format.

Strengths

  • Focused single-purpose transformation.
  • Keeps response post-processing reusable.
  • Simple component boundary aids testing.

Risks

  • Tag parsing can fail on malformed or nested patterns.
  • Over-filtering may remove useful output content.
  • Behavior differences can appear across model families.

Recommendations

  1. Test malformed and nested tag cases explicitly.
  2. Document exact filtering rules and guarantees.
  3. Keep logic deterministic and side-effect free.
