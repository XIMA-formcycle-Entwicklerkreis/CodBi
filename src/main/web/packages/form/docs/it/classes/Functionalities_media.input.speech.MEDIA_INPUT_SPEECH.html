    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): void

      Aggiunge un pulsante del microfono a un input type="text" o textarea per input da voce a testo tramite l'API Web Speech.

      Parametri di configurazione:

      • VoiceHotkey: scorciatoia da tastiera per attivare/disattivare la registrazione. Impostazione predefinita: "Alt+A".
      • Lingua: tag della lingua BCP-47 per il riconoscimento (ad es. de-DE, en-US). Se omesso, viene utilizzata la lingua predefinita del browser.
      • Segnaposto: testo segnaposto personalizzato per il campo. Predefinito: il tasto di scelta rapida combo preceduto da un'emoji del microfono (ad esempio 🎙 Alt+A). Visualizzato solo quando "ShowHint" è "true".
      • ShowHint: se impostato su true, mostra il suggerimento del tasto di scelta rapida come testo segnaposto. Impostazione predefinita: "falso".

      Informativa sulla privacy (DSGVO/GDPR):

      L'API Web Speech trasmette l'audio registrato a un servizio cloud esterno per elaborazione del parlato in testo. Il servizio specifico dipende dal browser (ad esempio Google Cloud per Chrome, Microsoft Azure per Edge). I dati audio allontana dal dispositivo dell'utente e viene trattato su server di terze parti.

      Quando implementa questa funzionalità, il titolare del trattamento dei dati deve informare gli utenti su questo trasferimento di dati in un'informativa sulla privacy (Datenschutzerklärung) in ai sensi dell'art. 13 DSGVO. Ciò include l'identificazione del destinatario del file dati audio, finalità del trattamento e base giuridica. In caso contrario costituisce una violazione del DSGVO.
