    • functionality(toLoad: { [key: string]: unknown }, toProcess: Element): undefined

      Questa funzionalità applica una determinata funzionalità a object toProcess a seconda se una determinata condizione è soddisfatta o meno. Le funzionalità da applicare sono definite dagli attributi del tag HTMLInputElement. Quegli attributi iniziare con cb_T_, per gli attributi da applicare quando il tag HTMLInputElement e il valore "riferimento" viene confrontato con successo dalla "modalità" specificata o con cb_F_ in caso contrario. Ad esempio, per definire un JSON.SET che imposta la proprietà style.display del "target" sul "target" sia per il successo che per il fallimento sono necessari anche i seguenti attributi per il tag HTMLInputElement: cb_T_FUNC, cb_T_Path, cb_T_Property, cb_T_ToSet, cb_F_FUNC, cb_F_Path, cb_F_Property, cb_F_ToSet. L'omissione degli attributi T o F non comporterà che accada nulla in caso di successo (T) o fallimento (F).

      Parametro di configurazione:

      • Riferimento: il valore con cui deve essere confrontato il valore di HTMLInputElement.
      • Modalità: definisce la modalità di confronto da applicare al valore di HTMLInputElement e al valore di "riferimento". Le modalità disponibili sono GTE (maggiore o uguale), GT (maggiore), LTE (inferiore o uguale), LT (inferiore a), EQ (uguale) e NEQ (non uguale).
      • Target: Il Element dove applicare una delle funzionalità specificate a seconda che il data "condizione" è soddisfatta o meno o un selettore CSS. Per lavorare in un contenitore ripetitivo è obbligatorio un selettore CSS poiché la funzionalità esegue il query relativa al tag HTMLInputElement.
      • DateFormat: un string facoltativo che specifica il formato di cui è il candidato. Se questo parametro non è indefinito attiva il valore della trasformazione del campo con tag in un Date prima di confrontarlo con il riferimento. Se non specificato, si presuppone che il formato sia MM/GG/AAAA o un formato analizzabile da Date costruttore.
      • Candidato: Element dove ottenere il valore da confrontare o un selettore CSS. Per lavorare in un contenitore ripetitivo è obbligatorio un selettore CSS poiché la funzionalità esegue il query relativa al tag HTMLInputElement.
